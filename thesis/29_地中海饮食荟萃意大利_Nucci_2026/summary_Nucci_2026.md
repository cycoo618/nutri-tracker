## 2. 研究类型

系统综述与荟萃分析（Systematic Review & Meta-analysis）。

采用 **NUTRIGRADE** 方法（专为营养流行病学研究设计的证据等级评估体系），对前瞻性和回顾性队列研究进行汇总分析，评估地中海饮食依从性与全因死亡率之间的剂量-效应关系。

## 5. 核心结果

### 5.1 主效应：剂量-效应分析（每 1 分 MD 评分递增）

| 分析指标 | 结果 | 注释 |
|---------|------|------|
| 合并 RR（每 1 分递增） | **0.96**（95% CI: 0.95–0.97） | 随机效应模型，p < 0.001 |
| 每 1 分递增的死亡风险降低幅度 | **约 4%** | 呈线性剂量-效应关系 |
| 证据等级（NUTRIGRADE） | 中等确定性（Moderate certainty） | |
| 异质性 | 中至高度（原文报告，详见原文 I² 值） | |

### 5.2 比较最高 vs 最低依从性组（五分位数分析）

| 五分位 | 合并 RR | 95% CI |
|--------|--------|--------|
| Q1（最低，参考） | 1.00 | — |
| Q2 | 0.85 | 0.73–0.98 |
| Q3 | 0.80 | 0.69–0.93 |
| Q4 | 0.77 | 0.66–0.90 |
| Q5（最高） | 0.68 | 0.58–0.79 |

*结论：与最低依从组相比，最高依从组全因死亡风险降低约 32%。*

### 5.3 亚组分析

| 亚组 | 效果方向 | 注释 |
|------|--------|------|
| 男性 vs 女性 | 一致性保护效应 | 性别间无显著差异 |
| 老年人 vs 中年人 | 一致性保护效应 | 年龄层间无显著差异 |
| 地中海国家 vs 非地中海国家 | 一致性保护效应 | 跨文化验证效应稳健 |

## 6. 方法学特点

| 要素 | 说明 |
|------|------|
| 证据分级体系 | NUTRIGRADE（专为营养流行病学研究设计，区别于 GRADE） |
| 合并统计量 | 随机效应模型合并 RR，采用 DerSimonian-Laird 法或类似方法 |
| 异质性评估 | I² 统计量；来源：研究人群、饮食评估工具、随访时长差异 |
| 发表偏倚 | Funnel plot + Egger/Begg 检验 |
| 敏感性分析 | 逐一剔除单项研究的剔除分析，结果具有稳健性 |

## 8. 机制概述（综述讨论部分）

地中海饮食降低全因死亡风险的可能作用通路（文中讨论，非直接测量数据）：

| 通路 | 机制 |
|------|------|
| 抗炎效应 | 橄榄油多酚、鱼类 Omega-3 降低 CRP、IL-6、TNF-α |
| 抗氧化 | 蔬菜/水果富含多酚、维生素 C/E，减少氧化应激 |
| 肠道微生物组 | 高纤维食物促进 SCFA 产生菌，改善肠屏障 |
| 代谢保护 | 改善胰岛素敏感性、降低 TG/LDL，减少代谢综合征风险 |
| 心血管保护 | 降低血压、减少动脉粥样硬化进展 |
| 表观遗传 | 多酚调节 DNA 甲基化、组蛋白修饰，减缓生物衰老 |

## 9. 局限性

- 所有纳入研究均为观察性队列研究，无法完全排除残差混杂（生活方式因素、教育水平、社会经济地位）
- 饮食评估依赖问卷自报（FFQ 或 24h 回忆），存在测量误差
- 不同研究使用不同 MD 评分系统，存在分类定义异质性
- 研究多集中于欧洲和北美人群，在亚洲、非洲等人群中的可推广性有限
- 大多数研究横跨 10–20 年，饮食模式可能随时间改变，但测量通常仅在基线进行（单次快照）
- 无法评估地中海饮食各组成成分（食物、营养素）的独立贡献
- 出版偏倚：正向结果更易发表
- 文中中等确定性证据等级反映了上述方法学局限

## 10. Action Items

### 整体饮食模式转变
- 以地中海饮食为基础框架调整每日饮食，核心是增加蔬果和豆类，以橄榄油替代黄油和精炼植物油
- 将每周鱼类摄入频率提高至 ≥2 次（优先多脂鱼：沙丁鱼、三文鱼、鲭鱼）
- 每日摄入一小把（约 30 g）坚果（核桃、杏仁、开心果）

### 减少加工食品和红肉
- 将红肉摄入限制在 ≤2 次/周，以豆类（扁豆、鹰嘴豆）替代部分动物蛋白
- 减少加工食品、含糖饮料，以全谷物替代精制谷物

### 评分监测
- 可使用 MEDAS 评分（14 分量表）或 Trichopoulou score 自评当前饮食依从性
- 本荟萃分析显示每 1 分递增对应约 4% 死亡风险降低，持续累积得分改善具有可量化的长期效益

### 可推广性
- 非地中海文化地区同样显示保护效应，表明地中海饮食核心原则（植物性食物为主、高质量脂肪、减少加工食品）可在不同文化背景下落地

---

## 11. 一句话总结

综合 54 个队列研究共 183 万人的荟萃分析表明，地中海饮食依从性每提高 1 分，全因死亡风险降低约 4%（合并 RR = 0.96, 95% CI: 0.95–0.97）；最高依从组死亡风险较最低依从组低约 32%，效应在不同性别、年龄段和地域人群中保持一致——中等确定性证据，观察性设计无法排除所有混杂因素。
