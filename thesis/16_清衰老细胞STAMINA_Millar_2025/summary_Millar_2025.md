# 衰老细胞清除改善认知与步行能力：STAMINA导航试验

## 发表信息

| 项目 | 内容 |
|------|------|
| 标题 | A pilot study of senolytics to improve cognition and mobility in older adults at risk for Alzheimer's disease |
| 期刊 | *eBioMedicine*（The Lancet 旗下） |
| 发表日期 | 2025年2月25日 |
| DOI | 10.1016/j.ebiom.2025.105612 |
| PMC | PMC11907475 |
| 机构 | Hebrew SeniorLife, Hinda and Arthur Marcus Institute for Aging Research（波士顿） |
| 资助方 | 美国国家老龄化研究所（NIA），资助编号 R21AG073886 和 R33AG061456 |

## 研究类型

12周**单臂开放标签前后对照导航试验（Single-arm Open-label Pre-post Pilot Study）**。研究目的为评估达沙替尼+槲皮素（D+Q）联合用药清除衰老细胞的可行性、安全性，以及对认知和运动功能的初步效果，为后续大规模RCT提供样本量估算和操作可行性数据。

> **方法学含义**：单臂无对照设计，所有参与者均接受干预，结果变化无法排除安慰剂效应、学习效应（测量工具）和自然时间变化的影响。试验目的不是确证疗效，而是测试流程可行性和信号探索。

## 研究对象

| 特征 | 详情 |
|------|------|
| 样本量 | N = 12 |
| 年龄要求 | ≥65 岁 |
| 入选条件（双标准） | 步速减慢（slow gait speed）**且** 轻度认知障碍（MCI） |
| 临床意义 | 步速慢+MCI 为阿尔茨海默病（AD）的双重前驱风险因素 |
| 招募范围 | 约10%的电话筛查对象完成干预（体现招募难度） |
| 随访时长 | 12 周 |

**注**：N=12 的样本量极小，任何统计结论的解读必须高度谨慎，本研究的设计初衷不是得出确定性结论。

## 研究方法

| 方法 | 内容 |
|------|------|
| 干预方案 | 达沙替尼（Dasatinib）100 mg + 槲皮素（Quercetin）1250 mg，每次口服连续2天 |
| 给药频率 | 每2周一个周期，共6个周期（12周） |
| 总计服药天数 | 12天（分6个周期完成） |
| 评估时间点 | 基线（干预前）、第12周（干预后） |
| 主要测量 | 招募率、不良事件、功能结果绝对变化值、生物标志物百分比变化 |
| 统计方法 | Wilcoxon符号秩检验（前后比较），Spearman相关分析（功能与生物标志物关联） |

## 测量指标

| 类别 | 指标 |
|------|------|
| 认知功能 | 蒙特利尔认知评估量表（MoCA，0–30分） |
| 步态与移动能力 | 步速（m/s）、步幅（stride length, m）、6分钟步行距离（6MWT） |
| 衰老细胞负荷指标（血浆） | p21（CDKN1A）、p16（CDKN2A）蛋白水平 |
| 炎症/SASP标志物 | IL-6、TNF-α（肿瘤坏死因子α）等衰老相关分泌表型（SASP）成分 |
| 可行性指标 | 招募率、依从率（药物服用完成率）、不良事件发生率 |

## 各组数据对比

本研究为单臂设计，无对照组。结果呈现基线→干预后的变化值。

| 指标 | 基线均值 | 变化值（均值） | 95% CI | 是否显著 |
|------|---------|--------------|--------|---------|
| MoCA（全体） | — | +1.0 分 | −0.7, 2.7 | 否（p 未达显著） |
| MoCA（最低基线亚组，18–25分） | 18–25 分 | +2.0 分 | 0.1, 4.0 | **是** |
| 步幅（全体） | — | +0.031 m | −0.003, 0.066 | 否（p 未达显著） |
| IL-6（全体） | — | −15.5% | −39.8, 8.8 | 否（p 未达显著） |

> 所有结果均为趋势性改善，仅低基线MoCA亚组达到统计显著性。该亚组的数据未预先注册为主要终点。

## 核心结果

### 认知功能

整体样本 MoCA 平均提高 1.0 分（95% CI −0.7, 2.7），未达统计显著。但在基线认知最低的亚组（MoCA 18–25分）中，干预后提高 2.0 分（95% CI 0.1, 4.0），达到统计显著。

2分的临床意义：MoCA 量表中，5分被认为是最小临床重要差异（MCID）的近似值，2分的改善属于亚临界范围，但对于高风险人群可能具有早期预防意义。

### 步态功能

步幅（stride length）平均增加 0.031 m（95% CI −0.003, 0.066），方向一致但未达统计显著。置信区间跨越零，无法排除无效假设。

### 炎症生物标志物

IL-6 下降 −15.5%（95% CI −39.8, 8.8），方向符合 SASP 抑制的预期，但宽置信区间和样本量（N=12）导致无法得出统计结论。

### 安全性

全程无严重不良事件（SAE）发生。轻度不良事件（AE）发生率在可接受范围内，未出现达沙替尼相关严重毒性（如心律失常、血液毒性）。

## 机制分析

达沙替尼+槲皮素（D+Q）是目前人类临床试验中最常用的衰老细胞清除（Senolytic）组合方案，作用机制如下：

| 机制 | 说明 |
|------|------|
| 达沙替尼（BCR-ABL/Src 激酶抑制） | 阻断衰老细胞的 SRC/PI3K/AKT 抗凋亡生存信号，使其恢复对凋亡的敏感性 |
| 槲皮素（多靶点黄酮类化合物） | 抑制衰老细胞中过度激活的 Bcl-2 家族蛋白（BCL-xL/BCL-2/BCL-W），与达沙替尼协同促凋亡 |
| SASP 抑制 | 清除衰老细胞后，局部 IL-6、IL-8、TNF-α 等炎症因子释放减少，改善组织微环境 |
| 神经炎症减轻 → 认知改善 | 衰老神经胶质细胞（senescent astrocytes/microglia）被清除后，神经炎症降低，可能改善突触功能和认知 |
| 神经肌肉单元改善 → 步态改善 | 肌肉组织中衰老卫星细胞（satellite cells）清除后，肌纤维再生能力恢复，步态功能趋向改善 |

| 分析框架 | 内容 |
|---------|------|
| 高 vs 低衰老细胞负荷亚组 | 研究进行了探索性亚组分析：基线衰老细胞负荷高的参与者效果更明显，符合机制预期 |
| MoCA改善集中于低基线亚组 | 认知受损更重者基线 SASP 水平可能更高，因此清除效果更显著 |

## 局限性

- 样本量极小（N=12），统计检验力严重不足，所有结果均需在更大规模试验中复现
- 单臂无对照设计，无法排除安慰剂效应（尤其是MoCA测量的练习效应）、自然波动
- 评估者和参与者均知晓治疗方案（开放标签），主观量表结果存在测量偏倚风险
- 随访仅12周，无法评估长期衰老细胞清除效果或安全性（再生后再积累问题）
- 仅约10%筛查者参与完成，提示高度选择偏差，结果外推受限
- 主要显著结果（低基线MoCA亚组+2分）为事后亚组分析，非预设主要终点
- 达沙替尼为BCR-ABL酪氨酸激酶抑制剂，原适应证为白血病，在健康老年人中的长期应用风险（心脏毒性、出血风险）尚不完全清楚
- 生物标志物（IL-6、p16、p21）变化均未达统计显著，无法确认衰老细胞负荷是否实质减少

## Action Items

### 如果你是65岁以上高风险人群（步速慢 + 认知担忧）
- 目前不建议自行使用达沙替尼+槲皮素：均为具有显著毒性风险的药物，且疗效尚未在对照试验中确认
- 达沙替尼是化疗药物（BCR-ABL抑制剂），不适合在没有严密医学监测的情况下自我给药
- 槲皮素单独使用（补充剂形式）的临床证据远弱于 D+Q 组合，不建议期望等同效果

### 如果你想跟进该领域进展
- 本研究为后续 R33 阶段大规模RCT（预期样本量更大、含对照组）提供了可行性数据
- 关注 Mayo Clinic、Hebrew SeniorLife 等机构的衰老细胞清除 RCT 进展（UNITY Biotechnology 的关节炎试验、IDOTA 阿尔茨海默病试验）
- 衰老细胞学说目前仍处于人类临床转化早期阶段，需谨慎对待新闻标题式的过度解读

### 行为层面的衰老细胞管理（有明确证据的策略）
- 规律有氧运动可减少组织衰老细胞积累（多个动物和部分人类研究证实）
- 热量限制通过 mTOR/AMPK 通路降低 SASP 炎症信号（参见论文 #17）
- 地中海饮食中的多酚（槲皮素的天然来源包括洋葱、苹果）对衰老细胞有间接清除效果

## 一句话总结

12名有认知减退和步速减慢风险的老年人接受12周达沙替尼+槲皮素治疗，整体认知和步态改善未达统计显著，但基线认知最低的亚组 MoCA 显著提升 2 分，整体安全性良好——本研究为后续大规模RCT提供了可行性依据，尚不足以支持临床应用。
