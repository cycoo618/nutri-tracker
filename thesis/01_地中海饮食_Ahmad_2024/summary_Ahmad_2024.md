# 哈佛追踪2.5万人、长达25年：地中海饮食与死亡风险的关联证据

**来源：** Ahmad S et al., JAMA Network Open. 2024;7(5):e2414322  
**DOI：** 10.1001/jamanetworkopen.2024.14322  
**原文：** `Mediterranean Diet Adherence and Risk of All-Cause Mortality in Women - PMC.pdf`（同目录）  
**数据核验：** 核心统计数字经独立 sub-agent 对照原始论文逐项核验

---

## 一、这是什么类型的研究？可信吗？

这项研究是**前瞻性队列研究**，不是 RCT（随机对照试验）。

区别：RCT 将人随机分组给予不同干预，可以建立因果关系；队列研究记录真实生活习惯后长期追踪，只能说明相关性，无法排除所有混杂因素。

这项研究在队列研究里属于高质量：样本量大、随访时间长、随访完整率高，与过往数十篇同类研究的结论方向一致。

**发表信息：**

| 项目 | 内容 |
|------|------|
| 期刊 | JAMA Network Open（美国医学会旗下，全球顶级医学期刊） |
| 发表时间 | 2024年5月31日 |

**研究团队：** 哈佛医学院 + 布莱根妇女医院（Brigham and Women's Hospital）。

## 二、研究了谁？

| 项目 | 数据 |
|------|------|
| 总人数 | **25,315 名女性** |
| 职业背景 | 美国女性医疗专业人员（护士、医生等） |
| 入组时平均年龄 | 54.6 岁（标准差 7.1） |
| 招募时间 | 1993–1996 年 |
| 平均随访时长 | **24.7 年**（标准差 4.8） |
| 随访完整率 | **>99%** |
| 族裔构成 | 白人 94.9%；黑人 1.6%；亚裔 1.3%；西裔 0.9%；其他 0.4% |
| 追踪期间总死亡 | **3,879 人** |
| 其中癌症死亡 | 1,531 人 |
| 其中心血管死亡 | 935 人 |

**局限：** 参与者几乎全为白人、受过高等教育的医疗从业者。结论对男性、亚裔、年轻人的直接适用性需独立验证。

## 三、如何衡量"地中海饮食"？

入组时每人填写一份 **131 道题的饮食频率问卷**，回忆过去一年的饮食习惯。

评分采用基于 Trichopoulou 框架、由 Fung et al. (2009) 实现的 **9 分制系统**，每项符合条件得 1 分：

| 得分项 | 具体标准 |
|--------|---------|
| 蔬菜（不含土豆） | 摄入量高于样本中位数 |
| 水果 | 摄入量高于样本中位数 |
| 坚果 | 摄入量高于样本中位数 |
| 全谷物 | 摄入量高于样本中位数 |
| 豆类 | 摄入量高于样本中位数 |
| 鱼类 | 摄入量高于样本中位数 |
| 油脂质量 | 单不饱和脂肪/饱和脂肪比值高于中位数 |
| 红肉和加工肉 | 摄入量**低于**中位数 |
| 酒精 | 5–15g/天（约一小杯红酒） |

**三组分布：**

| 组别 | 分数 | 人数 |
|------|------|------|
| 低依从组 | 0–3 分 | 9,871 人 |
| 中依从组 | 4–5 分 | 9,184 人 |
| 高依从组 | 6–9 分 | 6,260 人 |

## 四、测了哪些生物指标？

入组时采集血液，在 **-170°C** 冷冻保存，共检测 **33 项生物标志物**，覆盖 10 个类别：

| 类别 | 具体指标 |
|------|---------|
| 传统血脂 | LDL-C、HDL-C、总胆固醇、甘油三酯 |
| 脂蛋白颗粒（LipoProfile IV） | LDL 颗粒数量和大小、HDL 颗粒数量和大小、TRL 颗粒数量和大小 |
| 炎症指标 | 超敏CRP、纤维蛋白原、sICAM-1、糖蛋白乙酰化 |
| 代谢综合指标 | HbA1c、胰岛素抵抗指数、5年糖尿病风险指数 |
| 小分子代谢物 | 柠檬酸、肌酐、同型半胱氨酸、丙氨酸 |
| 支链氨基酸 | 总量、缬氨酸、亮氨酸、异亮氨酸 |
| 载脂蛋白 | Apo AI、Apo B100、脂蛋白(a) |
| 体格指标 | BMI |
| 血压 | 收缩压、舒张压 |
| HbA1c | 糖化血红蛋白（单独类别） |

## 五、各组的饮食和生活方式差异

**饮食差异（每日份数中位数）：**

| 食物 | 低依从组 | 中依从组 | 高依从组 |
|------|:------:|:------:|:------:|
| 蔬菜 | 2.3 份 | 3.7 份 | **5.2 份** |
| 水果 | 1.3 份 | 2.1 份 | **2.8 份** |
| 全谷物 | 0.7 份 | 1.2 份 | **1.8 份** |
| 豆类 | 0.2 份 | 0.4 份 | **0.6 份** |
| 鱼类 | 0.1 份 | 0.2 份 | **0.3 份** |
| 红肉 | 0.6 份 | 0.6 份 | **0.5 份** |
| 加工肉 | 0.1 份 | 0.1 份 | **0.07 份** |

**生活方式差异：**

| 行为 | 低依从组 | 高依从组 |
|------|:------:|:------:|
| 当前吸烟 | 15.7% | 6.3% |
| 几乎不运动 | 44.7% | 26.0% |
| 平均 BMI | 25.0 | 24.2 |
| 几乎不饮酒 | 49.2% | 34.9% |

高饮食评分组本身就有更健康的生活习惯。统计上已做调整，但观察性研究无法完全排除这类混杂因素的影响。

## 六、核心数据

**各类死亡风险（高依从组 vs 低依从组）：**

| 死亡类型 | 风险变化 | 置信区间 | p 值 |
|---------|:-------:|:-------:|:---:|
| 全因死亡 | ↓ 23%（HR=0.77） | 0.70–0.84 | <0.001 |
| 心血管死亡 | ↓ 17%（HR=0.83） | 0.69–0.99 | 0.03 |
| 癌症死亡 | ↓ 20%（HR=0.80） | 0.69–0.92 | 0.002 |

**全因死亡的 HR 随调整层级的变化：**

| 调整层级 | HR | 95% CI |
|---------|:--:|:------:|
| 基础模型（年龄、处理因素、能量摄入） | 0.77 | 0.70–0.84 |
| + 生活方式调整（吸烟、运动、更年期等） | 0.89 | 0.82–0.98 |
| + 完全调整（再加全部生物标志物） | **0.92** | 0.83–1.00 |

加入越多控制变量，HR 数字越接近 1——这是统计调整的正常现象。最常被引用的 **23%（HR=0.77）** 是基础模型结果；完全调整模型的 HR=0.92 更保守，置信区间接近 1.00，说明调整完混杂因素后效应有所收窄。

## 七、哪些生物机制在起作用？

研究做了中介分析，计算每类生物指标能解释多少比例的死亡率降低：

| 生物机制 | 解释比例 |
|---------|:-------:|
| 小分子代谢物（同型半胱氨酸、柠檬酸等） | 14.8% |
| 炎症指标（CRP、纤维蛋白原等） | 13.0% |
| 甘油三酯富含脂蛋白颗粒（TRL） | 10.2% |
| BMI | 10.2% |
| 胰岛素抵抗 | 7.4% |
| LDL 胆固醇 | **<3%（不显著）** |
| 血压 | **<3%（不显著）** |
| **所有指标合计** | **~21.3%** |
| **无法解释的部分** | **~78.7%** |

LDL 胆固醇和血压的贡献均不显著，与"地中海饮食通过降低 LDL 保护心脏"的主流解释不一致。贡献较大的是炎症指标、代谢物变化和胰岛素敏感性。

所有 33 项指标合计只能解释约 21% 的获益。剩余约 79% 的机制在这项研究中无法被解释，研究者推测肠道微生物组、表观遗传学等路径可能是潜在方向，但目前尚无数据支撑。

## 八、研究的局限性

1. **人群单一：** 白人女性占 94.9%，全为受过高等教育的医疗专业人员，对男性、亚裔、年轻人的适用性需独立验证
2. **饮食只测了一次：** 入组时填问卷，此后 25 年的饮食变化未被追踪
3. **自我报告误差：** 问卷依赖记忆；BMI 和血压也是自报数据
4. **残余混杂：** 高饮食评分组本身生活方式更健康，统计调整后仍可能有未测量的混杂
5. **生物指标只测一次：** 33 项指标仅在入组时测定，无法反映 25 年间的动态变化
6. **BMI 和血压的角色模糊：** 二者既可作为混杂因素，也可作为中介变量，难以绝对区分

## 九、可以采取哪些行动？

**饮食调整（按重要性排序）：**

1. **增加蔬菜** — 高依从组每天平均 5.2 份（一份 ≈ 半碗煮熟蔬菜或一碗生蔬菜）
2. **每天吃完整水果** — 目标 2–3 份，以整颗水果为主，不以果汁代替
3. **用全谷物替换部分精制主食** — 糙米、全麦面包、燕麦，逐步替换
4. **增加豆类** — 豆腐、扁豆、鹰嘴豆、红豆，每周 3–4 次
5. **每周吃鱼 2–3 次** — 深海鱼优先（三文鱼、沙丁鱼、鲭鱼）
6. **用橄榄油代替黄油和猪油** — 优先初榨橄榄油
7. **减少红肉和加工肉** — 香肠、培根、火腿肠优先压缩；红肉每周 2–3 次以内
8. **用坚果替换零食** — 核桃、杏仁、腰果，每天约 30g

**基于生物机制的重点目标：**

| 目标机制 | 行动 |
|---------|------|
| 降低慢性炎症 | 减少加工食品、精制糖、反式脂肪；增加 Omega-3（深海鱼、核桃） |
| 改善胰岛素敏感性 | 减少精制碳水；增加膳食纤维；规律运动 |
| 优化代谢物组成 | 增加深绿色蔬菜（富含叶酸，有助于降低同型半胱氨酸水平） |

**认知调整：**
- 单纯盯着 LDL 数字不是最有效的策略——本研究显示 LDL 对地中海饮食获益的贡献不显著；整体饮食模式比单一指标更重要
- 酒精建议（5–15g/天）基于美国白人女性数据，不适合作为开始饮酒的理由，亚裔人群需参考针对性研究

---

## 十、结论

这项研究的主要结论：在 25,315 名女性、近 25 年的随访数据中，地中海饮食依从性最高组相比最低组，全因死亡风险低 23%，心血管死亡风险低 17%，癌症死亡风险低 20%。获益通过多条代谢通路同时发挥作用，没有单一主导机制。约 79% 的获益机制目前无法被已测量的生物指标解释。

---

*研究类型：前瞻性队列研究（非随机对照试验）。主体资助：NIH 政府基金。核心统计数字经独立 sub-agent 对照原始论文逐项核验。结论主要适用于中年女性群体，其他人群需参考针对性研究。*
